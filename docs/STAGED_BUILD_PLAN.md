# Staged Build Plan: Market-Driven Development

## Overview: Build → Test → Sell → Reinvest

This plan aligns development with market reality and cash flow. Stop building when you have enough to test with real customers, then use revenue to fund the next stage.

---

## Stage 1: Pilot-Ready MVP (Weeks 1-4)
**Goal:** Working software for pilot customers
**Investment:** €0-500 (your time + basic docs)
**Target:** 2-3 small municipalities willing to test

### Core Development (Weeks 1-4 - EXISTING PLAN)
- ✅ **Week 1:** Core skeleton + Budget Execution profile [DONE]
- ✅ **Week 2:** Validators + CKAN + Scheduler [DONE]  
- ⏳ **Week 3:** eInvoice Helper MVP
- ⏳ **Week 4:** NIS2 Logbook + Basic hardening

### Pilot Packaging (Week 4.5 - 2 days)
- **Simple Windows installer** (.exe, not .msi)
- **Basic user guide** (screenshots, step-by-step)
- **GDPR compliance docs** (DIY templates)
- **Basic support procedures** (email, phone hours)

### **STOP HERE FOR PILOT TESTING**
**What you have:**
- Working compliance automation for 3 modules
- Professional-looking installation
- Basic documentation
- Legal compliance (GDPR)

**What you DON'T have yet:**
- Multi-user authentication
- Enterprise security features
- Professional certifications
- Advanced DevOps

## Development Stopping Points

### ✋ **STOP AFTER WEEK 4** 
**Don't build these yet:**
- Complex authentication systems
- Enterprise security features  
- Advanced DevOps/monitoring
- Multi-tenancy
- API endpoints
- Source code escrow
- Professional certifications

**Why:** You need pilot feedback before investing in enterprise features

### ✋ **STOP AFTER STAGE 2**
**Don't build these until you have revenue:**
- Advanced integrations (SAP, Oracle)
- High availability/clustering  
- Advanced analytics/reporting
- Mobile applications
- Cloud deployment options
- Advanced workflow engines

**Why:** These are expensive to build and maintain without proven demand

## Investment Timeline & ROI

### Stage 1: Core Product (€500 investment)
- **Time:** 4.5 weeks
- **Cost:** €0-500 (documentation, basic legal)
- **Revenue Target:** 2-3 pilots × €0-2k = €0-6k
- **Goal:** Validate market demand

### Stage 2: Professional Product (€5k investment)
- **Time:** 2 weeks development + external services
- **Cost:** €2k-5k (security assessment, professional packaging)
- **Revenue Target:** 10-20 customers × €5k-15k = €50k-300k
- **Goal:** Establish market presence

### Stage 3: Enterprise Product (€15k investment)
- **Time:** 3-4 weeks development + external services  
- **Cost:** €10k-15k (full audits, certifications)
- **Revenue Target:** 5-10 enterprise customers × €25k-50k = €125k-500k
- **Goal:** Premium market positioning

---

## Risk Management

### Technical Risks
- **Stage 1:** Keep it simple, focus on core functionality
- **Stage 2:** Address security basics, but don't over-engineer
- **Stage 3:** Full enterprise features only after proven demand

### Financial Risks  
- **Never invest more than previous stage revenue**
- **Always maintain 3-6 months runway**
- **Partner with local integrators to share costs/risks**

### Market Risks
- **Start with friendly pilot customers**
- **Get written testimonials and references**  
- **Validate pricing at each stage**

## Bottom Line Strategy

**Phase 1:** Build core engine, test with friendly customers (€500 risk)
**Phase 2:** Use pilot success to justify professional packaging (€5k risk from pilot revenue)  
**Phase 3:** Use market traction to justify enterprise features (€15k risk from established revenue)

**Never spend money you don't have. Always validate before investing.**
